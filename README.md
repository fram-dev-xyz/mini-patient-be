# Fram Xtramile Test Be

This project is built using these libs:
- Java 21
- Spring-boot
- H2 Database
- Lombok
- Flyway

## Development server

To start the app, run:

```bash
mvnw clean spring-boot:run
```

The service is running on port 8080 (`http://localhost:8080/`)

To run the unit test, run:

```bash
mvnw test
```
